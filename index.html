V4 Broker

A personal Google Sheets integration for controlled workflow checks in V4 Research Lab.

V4 Broker is operated by Michael Gould for his own use. It connects an authenticated operator to a private service that can validate a designated Google Sheet and record approved test evidence.

What the application does

  • Checks the structure and contents of a specifically configured spreadsheet tab.
  • Records an explicitly approved test result and checks that the recorded evidence is consistent.
  • Keeps local audit and recovery records so interrupted work can be reviewed.

Google consent grants API permission. Each test still requires separate operator authorization. Connecting an account does not itself start a test or authorize scientific execution.

Google account access

The application requests Google Sheets access and an offline authorization token so its private service can maintain an authorized connection. Google’s Sheets permission is broad; the broker’s configured workflow restricts its use to the designated test target. The application does not request Gmail access.

This public website provides application and privacy information. It does not provide public access to the broker or collect Google credentials.
