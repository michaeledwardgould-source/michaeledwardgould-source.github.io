Privacy policy

V4 Broker · Last updated September 24, 2026

This policy describes V4 Broker, a personal application operated by Michael Gould for controlled Google Sheets workflow checks in V4 Research Lab. It also describes this public information website.

Information the broker accesses

When authorized by the account owner, the broker can access the configured spreadsheet’s identifier, tab names and properties, column headers, and cell contents needed to validate the target and reconcile approved test evidence. It can append an approved evidence record to the designated tab.

The Google Sheets permission shown during consent is broader than a single spreadsheet. The broker’s operating configuration and authorization checks limit its activity to its designated target. Google consent alone does not authorize a test. The application does not request access to Gmail messages or contacts.

The setup stores an OAuth client identifier and secret, a Google refresh token, and short-lived access tokens. These let the service access the Sheets API with the account owner’s permission. Google handles sign-in; the broker does not receive the Google account password.

The broker also processes its enrolled operator identity, client-certificate information, authorization decisions, timestamps, test evidence, and operational or recovery records.

How information is used

Information is used to authenticate the operator, maintain the authorized Google connection, validate the designated Sheet, perform specifically approved workflow checks, record evidence, prevent duplicate or unauthorized actions, and support troubleshooting and recovery.

Google user data is not sold, used for advertising, or used to train generalized artificial-intelligence or machine-learning models. Any future change that introduces a new use of Google data will require an updated disclosure and the account owner’s consent before that use begins.

Storage and access

The private broker runs in the operator’s Google Cloud project. Credentials, configuration, and operational records are stored in access-restricted files or local databases. Setup copies of credentials may also remain in the operator’s Cloud Shell storage. Google API connections use HTTPS, and operator connections to the broker use mutual TLS authentication.

Snapshots and backups may contain broker configuration, credentials, and operational records. Access is controlled through the operator’s Google Cloud permissions. Google Sheets retains the spreadsheet data in the authorized Google account.

The operator and the infrastructure services needed to run the application, principally Google APIs and Google Cloud, handle the data for these purposes. Broker credentials and spreadsheet contents are not intentionally published to this website or its public GitHub repository. Information may be disclosed when legally required.

Retention and deletion

Credentials are retained while needed for the authorized connection. Evidence, audit records, and recovery files are retained for the operator’s workflow and recovery needs until the operator removes them. Scheduled snapshots follow their configured retention policy; manually retained snapshots and restore disks remain until separately deleted. Deleting a working copy does not immediately remove a retained backup.

The account owner can remove V4 Broker’s access through the Google Account connections page. Revoking access prevents further authorized Google API access once it takes effect; it does not automatically delete existing spreadsheet entries, local records, setup credential copies, or backups.

For access, deletion, or retention requests, contact michaeledwardgould@gmail.com. The operator can review the relevant working copies and backups and explain any records that must be retained.

This website

This information website has no sign-in form, advertising, analytics scripts, or application-set cookies. GitHub Pages hosts the site. GitHub records visitor IP addresses for security purposes as described in the GitHub Privacy Statement. Visiting this website does not connect a Google account to the broker.

Google API data commitments

V4 Broker’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
